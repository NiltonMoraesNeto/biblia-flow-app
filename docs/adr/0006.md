# ADR-0006 — Widgets nas duas plataformas

Status: proposed

Data: 2026-10-21

## Contexto

Mostrar conteúdo devocional fora do app com deep link.

## Decisão

Spike por plataforma para avaliar API Expo e extensões nativas, snapshots autorizados e atualização best effort.

## Alternativas

Assumir que uma tela RN já é widget.

## Consequências e validação

M8 exige build de desenvolvimento, capabilities e validação iOS/Android. Não expor diário nem prometer atualização contínua.

Responsável pela decisão: proprietário do produto; proposta exige revisão antes da implementação.
