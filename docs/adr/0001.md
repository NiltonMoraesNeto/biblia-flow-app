# ADR-0001 — Stack mobile

Status: accepted

Data: 2026-10-21

## Contexto

Stack indicada pelo proprietário para iOS/Android.

## Decisão

React Native, Expo SDK 58 e TypeScript strict; template oficial e lockfile npm.

## Alternativas

Nativo puro e PWA.

## Consequências e validação

Integração rápida; módulos nativos e atualizações de SDK exigem builds próprios. Não há promessa de Expo Go para todas as features.

Responsável pela decisão: proprietário do produto; proposta exige revisão antes da implementação.
