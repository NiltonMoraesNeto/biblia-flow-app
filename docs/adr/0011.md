# ADR-0011 — Runner de UI local para M1-T03

Status: superseded somente no fluxo de execução por [ADR-0012](0012.md).

Data: 2026-10-22

## Contexto

M1-T02 concluída por aceite do proprietário. Jest/Testing Library verificam rotas reais,
mas usam mocks nativos e não comprovam renderização, gestos, safe areas ou leitores de tela.
M1-T03 requer runner de UI e aprovação visual em iOS/Android. O proprietário tem iPhone 14
e poderá usar o Android da esposa quando disponível; instalará os aplicativos necessários.

## Decisão

Usar Maestro CLI local, instalado por Homebrew (2.11.0 nesta execução, com OpenJDK 27).
Sem dependência npm/nativa no app, conta Maestro Cloud ou EAS. Analytics desativado nos
scripts de teste. Java é selecionado por JAVA_HOME no processo, sem editar perfis globais.
SDK Expo 57 mantido. testID em controles permite seletores estáveis, preservando seus
nomes e estados acessíveis em português. Textos esperados nos fluxos são dados de teste,
alinhados a src/i18n/pt-BR.ts, sem criar uma segunda fonte de textos para o aplicativo.

Fluxos recebem APP_ID e APP_URL; não fixar endereço de rede ou conta pessoal. Expo Go
deve estar previamente aberto no projeto, com eventuais diálogos iniciais resolvidos.
O fluxo de fonte ampliada exige ampliar a fonte no SO antes de executá-lo, sem limitar
a escala ou alterar configurações pessoais automaticamente.

No iOS, Maestro local usa simulador; o iPhone físico permanece no roteiro manual.
No Android, preparar Expo Go SDK 57 no aparelho; automação por USB requer também
platform-tools e depuração USB autorizada pelo dono. A execução sem aparelho não conta
como aprovação: check-syntax apenas valida os arquivos, não a renderização ou seletores nativos.

## Alternativas

Detox exigiria integração/build nativo adicional; Appium aumentaria a configuração inicial.
Somente Jest não satisfaria o critério de runner nativo. Serviços em nuvem introduziriam
contas/custos sem necessidade neste incremento.

## Consequências e validação

Fluxos em .maestro, comandos npm test:ui/test:ui:large-text/test:ui:syntax e roteiro
em [M1-T03-validation](../engineering/M1-T03-validation.md). Saídas locais em artifacts/ui,
ignoradas pelo Git. Não usar dados reais do diário nos fluxos ou capturas.
Maestro instalado e sintaxe aprovada; execução nativa ainda pendente de dispositivo.
VoiceOver/TalkBack, geometria de safe areas, contraste percebido e aprovação visual
continuam exigindo revisão humana. M1/F01 não concluídas por instalação de ferramenta.
