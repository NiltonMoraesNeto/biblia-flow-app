# ADR-0009 — SDK 57 para revisão com Expo Go

Status: accepted

Data: 2026-10-21

Substitui [ADR-0001](0001.md) somente na versão do SDK e das dependências compatíveis.

## Contexto

A revisão visual de M1-T01 no iPhone foi impedida pela incompatibilidade entre o projeto
SDK 58 e o Expo Go instalado da App Store. O proprietário usa uma conta Apple comum
e solicitou explicitamente a migração para SDK 57 nesta data.

## Decisão

Adotar Expo SDK 57 e alinhar React, React Native, tipos e módulos Expo à matriz dessa
versão com Expo CLI. Manter TypeScript strict, Node 24, temas e o escopo de M1-T01.
O lockfile registra as versões exatas. Não avançar para navegação nesta alteração.

## Alternativas

Manter SDK 58 com development build, ou aguardar um Expo Go compatível na App Store.

## Consequências e validação

A revisão usa Expo Go compatível com SDK 57; execução no iPhone ainda requer confirmação
do proprietário. Widgets e módulos nativos futuros continuam exigindo builds próprios.
Validar dependências, npm run check e exportações Metro nas duas plataformas;
resultados e limitações em [M1-T01-validation](../engineering/M1-T01-validation.md).

Referências: [SDK 57](https://expo.dev/changelog/sdk-57),
[alinhamento de dependências](https://docs.expo.dev/workflow/upgrading-expo-sdk-walkthrough/).

Responsável pela decisão: proprietário do produto, por solicitação explícita.
