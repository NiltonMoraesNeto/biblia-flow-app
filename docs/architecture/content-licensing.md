# Gate de conteúdo

ARC é preferência do produto, não autorização. Nenhum corpus bíblico está incluído nesta base.
Antes de importar, preencher o registro abaixo com evidências verificáveis e revisão do proprietário.
Não presumir licença a partir do nome Almeida, idade da tradução ou disponibilidade em uma API.

| Campo obrigatório                                           | Estado inicial |
| ----------------------------------------------------------- | -------------- |
| Edição, revisão, idioma, fonte e titular                    | Pendente       |
| Termos/autorização e evidência arquivada                    | Pendente       |
| Distribuição iOS/Android e territórios                      | Pendente       |
| Armazenamento offline e redistribuição                      | Pendente       |
| Notificações, widgets, compartilhamento e limites de trecho | Pendente       |
| Atribuição, alterações permitidas e expiração               | Pendente       |
| Responsável, data de revisão e hash do corpus               | Pendente       |

Se ARC não for licenciada, manter leitura bloqueada por fonte ou selecionar alternativa comprovadamente
autorizada com decisão explícita. Fixtures sintéticas não devem se apresentar como tradução bíblica.
Orações/reflexões exigem autoria/licença e revisão editorial; sem scraping ou textos atribuídos sem prova.
